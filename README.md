# TWIN Tools

This mono-repository contains some of the tooling packages that the rest of the TWIN packages depend on.

## Packages

- [tools-core](packages/tools-core/README.md) - Shared components for the tools.

## Apps

- [ts-to-openapi](apps/ts-to-openapi/README.md) - Tool to convert TypeScript REST route definitions to OpenAPI Specifications.
- [ts-to-schema](apps/ts-to-schema/README.md) - Tool to convert TypeScript types to JSON Schemas.
- [ts-to-jsonld-context](apps/ts-to-jsonld-context/README.md) - Tool to convert TypeScript types to JSON-LD Contexts.
